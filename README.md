# Expense Tracker

แอป React Native + Expo สำหรับเว็บ/PWA, iPhone และ Android ตามแผน Expense Tracker อ่าน QR ภายในระบบ มี OCR (Tesseract ในตัว API) ช่วยร่างยอด/วันเวลาจากภาพสลิป ไม่ใช้บริการตรวจสลิปภายนอก บันทึกยอดใช้ไปและโอนระหว่างบัญชี (ไม่มีรายรับ) รองรับเงินสด บันทึกเอง สลิปรอเติมข้อมูล และ LINE Flex

## เปิดดูทันที

ต้องมี Node.js 22.17 ขึ้นไป และ npm ใช้ PowerShell:

```powershell
cd C:\Users\CHSNP\Desktop\SHZR\expense-tracker
npm ci
npm run dev
```

เปิด URL ที่ Expo แสดง แล้วกด **ลองข้อมูลตัวอย่าง** ทดลองบันทึก แก้ไข ลบ เชื่อมสลิป และดูรายงานได้ ข้อมูลโหมดนี้อยู่ในอุปกรณ์เท่านั้น ไม่ส่ง Drive/LINE และไม่ใช่ข้อมูลบัญชีจริง

ดูเวอร์ชัน build:

```powershell
npm run build
npm run preview
```

เปิด http://localhost:8081 เว็บ production เป็น PWA พร้อม manifest, icon และ service worker ซึ่งเก็บเฉพาะหน้าจอและไฟล์แอป ไม่เก็บ API หรือภาพสลิปส่วนตัว การใช้ข้อมูลจริงยังต้องเชื่อมอินเทอร์เน็ต

## ระบบเข้าสู่ระบบ

หน้า `/login` รองรับอีเมล/รหัสผ่าน, OTP อีเมล, Google, ลืมรหัสผ่าน และจดจำ session หน้า `/account` เชื่อมช่องทางเข้าบัญชีเดิม SMS ยังปิดไว้ตามค่าเริ่มต้น ตั้งค่าฟรีภายในโควตาตาม [docs/AUTH.md](docs/AUTH.md)

## ตั้งค่าระบบจริง

ทำตาม [docs/SETUP.md](docs/SETUP.md) ทีละส่วน: Supabase → Backend → Drive → เว็บ → LINE → Cron คีย์ลับเก็บใน `.env` หรือหน้า Environment Variables ของ Vercel เท่านั้น

ยังไม่มีการสร้างบัญชีบริการหรือ deploy จาก repo นี้ ต้องตั้งค่าบริการก่อนล็อกอินและใช้ Schedule บน Cloud ตามคำขอให้เตรียม repo/คู่มือก่อน

## มีอะไรบ้าง

- ภาพรวม: ยอดใช้ไป แยกบัญชี งบเดือน กราฟ และสถานะสลิป
- รายการ: ค้นหา กรองวัน บัญชี ประเภท หมวด แก้ไข/ลบ
- บันทึก: ยอดใช้ไป เงินสด และโอนระหว่างบัญชี
- รายงาน: วัน/สัปดาห์/เดือน เทียบช่วงก่อน แยกหมวด/บัญชี CSV และประวัติ LINE
- สลิป: อ่าน QR ร่าง OCR ดูภาพส่วนตัว เติมรายละเอียด เชื่อมรายการเดิม กันซ้ำ ลองอ่านใหม่ และลบสลิปที่ยังไม่บันทึก
- ตั้งค่า: แหล่ง Drive → บัญชีเงินจริง หมวด กฎผู้รับ งบ และเชื่อม LINE

MAKE กับ K-PLUS เป็นแหล่งสลิปแยกกัน ผู้ใช้กำหนดบัญชีเงินจริงให้แต่ละแหล่งได้ หากใช้บัญชีเดียวกัน ให้เลือกบัญชีเดียวกันในตั้งค่า ยอดใช้ไปคือรายการที่บันทึก ไม่ใช่ยอดคงเหลือธนาคาร

## QR ที่รองรับ

อ่านภาพ JPEG/PNG/WebP ด้วย `sharp` + `jsQR` ตรวจโครงสร้าง/CRC ของ Mini-QR ด้วย `promptparse` ได้รหัสธนาคารและเลขอ้างอิง ไม่เรียก API ตรวจสลิป และไม่ใช้ QR สำหรับรับชำระเป็นหลักฐานการโอนสำเร็จ

**Mini-QR ที่พบทั่วไปไม่มีจำนวนเงินและประเภทรายการ** จึงเก็บสถานะรอกรอก ไม่เดายอดจากภาพหรือเลขอ้างอิง เวอร์ชันนี้ยังไม่มีตัวถอด QR ที่สร้างธุรกรรมอัตโนมัติจากยอด เพราะยังไม่ได้รับสลิปตัวอย่างจริงทั้งสี่แหล่ง หากมีรูปแบบที่ให้ข้อมูลครบ จะเพิ่มตัวถอดพร้อม fixture และทดสอบก่อนเปิดใช้

ยอดจากสลิปที่เติมด้วยคนยังเป็นข้อมูลที่ผู้ใช้บันทึก ไม่ถือว่าธนาคารยืนยันแล้ว

## OCR

QR ใช้ระบุธนาคาร เลขอ้างอิง และกันซ้ำ ส่วน OCR อ่านยอด วันเวลา และชื่อจากภาพเป็น**ร่าง**เท่านั้น ผู้ใช้ต้องตรวจและเลือกชนิดรายการเอง (ใช้ไป/โอนระหว่างบัญชีตัวเอง) ก่อนบันทึกทุกครั้ง ไม่มีการสร้างรายการเงินอัตโนมัติจาก OCR

ใช้ Tesseract ในตัว API บน Vercel (`OCR_ENABLED=true`, `OCR_ENGINE=tesseract`) โมเดลรวมไว้ใน build ไม่ต้องตั้งอะไรเพิ่ม อ่านในรอบสแกนกลางคืน กด "ดึงสลิปตอนนี้" หรืออัปโหลดรูปเองในหน้าสลิปได้ทุกเวลา ทดสอบกับสลิปจริง 16 ใบ ยอด/วัน/เวลาถูก 16/16 แผนสำรองคือ Paddle บน GitHub Actions (กดรันเอง) ดู [docs/OCR.md](docs/OCR.md) ต้องรัน `003_ocr.sql` ก่อน

## ลบสลิป

หน้า "สลิป" ลบสลิปที่ยังไม่บันทึกได้ทีละใบหรือทั้งหมด รายการเงินที่บันทึกแล้วและไฟล์ต้นฉบับใน Drive ยังอยู่ นำเข้าใหม่ได้ ต้องรัน `004_delete_slips.sql` ก่อน

## โอนเข้าบัญชีตัวเอง

ตั้งค่า → "เลขบัญชีบนสลิป" (เลขเต็มหรือพร้อมเพย์ของแต่ละบัญชี) และ "ชื่อของฉันบนสลิป" ระบบเทียบเลขที่ปิดบางส่วนในสลิปก่อน แล้วใช้ชื่อเป็นตัวสำรอง ถ้าผู้รับตรงกับบัญชีหรือชื่อของคุณ แอปจะแนะนำว่าเป็นการโอนระหว่างบัญชี (ฟอร์มเลือก "โอน" ไว้ให้) และไม่นับในร่างยอดใช้ไปของ LINE เป็นเพียงคำใบ้ เพราะสลิปปิดนามสกุลบางส่วน ผู้ใช้ยืนยันเองทุกครั้ง เลขผู้โอนในสลิปยังใช้เลือกบัญชีต้นทางให้ (MAKE กับ K-PLUS แยกได้แม้เป็นธนาคารเดียวกัน) ถ้า OCR อ่านชื่อเดือนไม่ได้แต่อ่านวัน ปี และเวลาได้ และวันตรงกับวันอัปโหลด (หรือวันก่อนหน้า) จะเติมเดือน/ปีจากวันอัปโหลดพร้อมป้ายให้ตรวจ ต้องรัน `005_own_identity.sql` ก่อน

## จัดการข้อมูล

- **หน้าสลิป**: ดึงสลิปจาก Drive ช่วงวันที่ไหนก็ได้ (เลือกธนาคารได้) หรือ "เลือกรูปสลิป" อัปโหลดเอง → อ่าน QR + OCR → ฟอร์มบันทึก รูปที่อัปโหลดเองไม่ถูกเก็บ เก็บเฉพาะเลขอ้างอิงไว้กันซ้ำ ถ้าสลิปเดียวกันขึ้น Drive ภายหลัง รอบกลางคืนจะรู้ว่าซ้ำ
- **ฟอร์มบันทึก**: ไม่มีปุ่มเลือกประเภท เลือก "โอนเข้าบัญชีของฉันไหม" เป็นบัญชีปลายทาง = โอนระหว่างบัญชี ไม่เลือก = ใช้ไป
- **ตั้งค่า**: แก้/ลบบัญชี (ลบได้เมื่อไม่มีรายการ) หมวด (รายการในหมวดกลายเป็นยังไม่จัดหมวด) กฎจัดหมวด · เลขบัญชีบนสลิปอยู่ในแก้ไขบัญชี · "ดึงอัตโนมัติตั้งแต่วันที่" · ทดสอบส่ง Flex (ยอดวันนี้ถึงตอนนี้ ไม่กระทบรอบ 08:00)
- **รีเซ็ตเป็น 0**: ลบรายการเงินและสลิปทั้งหมด เก็บบัญชี หมวด กฎ การตั้งค่า และรูปใน Drive รอบกลางคืนดึงตั้งแต่วันที่รีเซ็ต ของเก่าเลือกดึงเองได้
- ต้องรัน `006_import_reset_manage.sql` ก่อน · ถ้ายังไม่รัน แอปจะแจ้ง "ฐานข้อมูลยังไม่อัปเดต" แทนการบันทึกเงียบ ๆ

## หน้าตาและการใช้งาน

- เปิดแอปทุกครั้งมีแอนิเมชัน (~2.2 วินาที): พื้นไล่สี → ไอคอนกระเป๋าเด้งเข้าพร้อมวงแสง → แท่งกราฟขึ้นทีละแท่ง → ชื่อแอป ไม่แสดงตัวเลขใด ๆ
- หน้าตั้งค่าเป็นการ์ดหัวข้อ แตะเพื่อเข้าไปตั้งค่าแต่ละเรื่อง
- ธีมสี: ค่าเริ่มต้นสว่าง เปลี่ยนเป็นมืดหรือตามระบบได้ที่ ตั้งค่า → การแสดงผล (จำในเครื่อง) โหมดมืดใช้พื้นถ่านเข้ม ครอบคลุมทุกหน้า
- รายงาน: เลือก วัน/สัปดาห์/เดือน แล้วกด ‹ › เลื่อนช่วง แตะชื่อช่วงเพื่อกลับช่วงปัจจุบัน
- แอปที่ติดตั้ง (PWA/มือถือ) ปัดจากขอบซ้ายเพื่อย้อนกลับแบบ iOS
- ไอคอนแอป/หัวแอป/หน้าล็อกอิน ใช้ `assets/icon-v2.png`

## โครงสร้าง

```text
apps/app/                    React Native, Expo Router, UI และ PWA
apps/api/                    Hono Node.js API / Vercel Function
packages/core/               ชนิดข้อมูล ยอดสตางค์ ช่วงเวลาไทย CSV
supabase/migrations/         PostgreSQL, RLS, RPC แบบ atomic, คิว/lease
supabase/schedule.sql        Supabase Cron เรียก API เฉพาะเวลาที่ตั้งไว้ (8 ครั้ง/วัน)
supabase/check-migrations.sql ตรวจว่ารัน migration ครบ (อ่านอย่างเดียว)
services/ocr/                Paddle OCR (Python) แผนสำรอง
integrations/apps-script/    สัญญาการอัปโหลดเดิม + ตัวอย่างอ้างอิง
docs/                        ตั้งค่า ออกแบบระบบ และผลตรวจ
tests/                       ทดสอบยอด QR API สิทธิ์และฐานข้อมูลจริงจำลอง
scripts/                     Preview, PWA, icon และตรวจ QR ตัวอย่าง
```

ฟอนต์ Noto Sans Thai และ Noto Sans บรรจุใน bundle ไม่โหลดจาก Google Fonts ระหว่างเปิดแอป
