# ปุ่มคู่ซ้าย–ขวา

ใช้ `ActionRow` ร่วมกันใน React Native และเว็บ ปุ่มคู่กว้างเท่ากัน อยู่แถวเดียวกัน แม้จอ 320 px ข้อความยาวขึ้นบรรทัดภายในปุ่มและความสูงทั้งคู่เท่ากัน ปุ่มเดี่ยวและตัวเลือกบัญชี/หมวดหมู่ใช้รูปแบบเดิม

| จุดใช้งาน | ซ้าย | ขวา |
|---|---|---|
| แก้ไขรายการ | ลบรายการนี้ | บันทึกรายการ |
| ยืนยันลบ | ยกเลิก | ยืนยันลบ |
| ปฏิทิน | ยกเลิก | เลือกวันนี้ |
| สลิปที่บันทึกแล้ว | ปิด | ดูรายการที่บันทึก |
| สลิปรอข้อมูล | ลองอ่าน QR ใหม่ ถ้าสถานะอนุญาต | กรอกยอดและรายละเอียด |
| เชื่อมสลิปกับรายการเดิม | ปิด | เชื่อมรายการที่เลือก |
| ตั้งค่า LINE | ดูตัวอย่าง LINE Flex | สร้างรหัสเชื่อม LINE |
| LINE ที่เชื่อมแล้ว | ยกเลิกการเชื่อม LINE | โหลดสถานะใหม่ |
| เข้าสู่ระบบเมื่อเชื่อม Supabase | ลองข้อมูลตัวอย่าง | เข้าสู่ระบบ |
| หน้า LINE Preview | กลับไปตั้งค่า | ดู/ซ่อน JSON |
| LINE Flex รายวัน/สัปดาห์/เดือน | ดูสลิปรอข้อมูล | ดู Dashboard |

ปุ่มก่อนหน้า/ถัดไปของรายการอยู่ซ้าย–ขวาของเลขหน้า กว้าง 90 px เท่ากัน ข้อความใน Choices ยาวสามารถขึ้นบรรทัดได้

Flex ที่ Backend ส่งและหน้าพรีวิวใช้ builder เดียวกัน footer เป็น horizontal box และแต่ละปุ่มมี flex 1 พร้อม adjustMode shrink-to-fit ตาม [เอกสาร LINE](https://developers.line.biz/en/docs/messaging-api/flex-message-layout/) ตัวอย่าง JSON ทั้งสามช่วงถูกสร้างใหม่แล้ว

## ตรวจแล้ว — 6 ตุลาคม 2569

- ตรวจทุกเส้นทางหลักบนเว็บ: ภาพรวม รายการ บันทึก รายงาน สลิป ตั้งค่า และ LINE Preview
- จอ 320×740: ปุ่มแก้รายการ/ยืนยันลบ ปฏิทิน ตั้งค่า LINE สลิปที่เชื่อมแล้ว Flex และพรีวิวอยู่แถวเดียวและกว้างเท่ากัน ไม่มีข้อความปุ่มหรือ document ล้นแนวนอน ปุ่มก่อนหน้า/ถัดไปหลัง build สุดท้ายกว้าง 90 px ทั้งคู่
- จอ 390×844: รายงานและหน้าแก้ไขรายการไม่มีข้อความปุ่มล้น; ปุ่มลบ/บันทึกกว้าง 148.8 px เท่ากัน
- เดสก์ท็อป 1440×1000: ปุ่มลบ/บันทึกกว้าง 354.2 px เท่ากัน ตั้งค่า LINE กว้าง 537.1 px และพรีวิวกว้าง 557.9 px เท่ากัน
- เปิดปฏิทินและยืนยันลบแล้วกดยกเลิก ตรวจเปิด/ปิด JSON และปุ่ม Flex ไปหน้าสลิป ไม่มีการบันทึกหรือลบธุรกรรมระหว่าง QA
- TypeScript ของ core/API/app, 36 tests และ Expo Web/PWA export ผ่าน ไม่เพิ่ม dependency

ยังไม่ได้ทดสอบ LINE จริง, login ที่ตั้งค่า Supabase แล้ว, สลิปที่ยังไม่เชื่อมในบริการจริง หรือ Expo Go บนอุปกรณ์จริง เนื่องจาก Cloud ยังไม่ได้ตั้งค่าและสลิปตัวอย่างปัจจุบันเชื่อมรายการแล้ว ตรวจโค้ดและ TypeScript ของสาขาเหล่านี้แล้ว
