# การทำงานประจำวัน (Cron + OCR + LINE)

ทุกอย่างอยู่ที่ **Vercel ที่เดียว** มีนาฬิกาปลุกชุดเดียวคือ Supabase Cron (`supabase/schedule.sql`)

```
┌─ Supabase Cron → ปลุก API บน Vercel (8 ครั้ง/วัน) ──────────
│ 23:35–00:00 ทุก 5 นาที : สแกน Drive + อ่าน QR + อ่าน OCR (Tesseract) → สร้างรายการสลิปพร้อมร่าง
│ 08:00                  : ส่ง Flex เข้า LINE
│ 08:05                  : ลองส่งซ้ำ ถ้า 08:00 ล้มเหลว
└──────────────────────────────────────────────────────────
นอกเวลานี้ไม่มีอะไรเรียก API ยกเว้นคุณกดปุ่มในแอป
```

แผนสำรอง: Paddle บน GitHub Actions (`.github/workflows/slip-ocr.yml`) **ไม่รันเอง** ใช้เมื่อกด Run workflow เท่านั้น (ดู [OCR.md](OCR.md))

## ไล่ตามเวลา

### 23:30 มือถืออัปโหลด (ระบบเดิม ไม่อยู่ใน repo)
iPhone Shortcuts → Apps Script → `Expense/slips/<ธนาคาร>/<YYYY-MM-DD>/ไฟล์.jpg` (วันที่ = วันอัปโหลด)

### 23:35–00:00 ทุก 5 นาที: สแกน + QR + OCR
1. pg_cron ส่ง POST `{expense_api_url}/api/internal/tick` พร้อม `Bearer {expense_cron_secret}` (จาก Vault)
2. API ตรวจรหัสกับ `CRON_SECRET` → ขอกุญแจ `tick` (กันทำงานซ้อนกับปุ่มในแอปและรอบอื่น)
3. สร้างงาน scan ให้แต่ละแหล่ง ช่วง **เมื่อวาน–วันนี้** (ไม่ย้อนก่อน "ดึงอัตโนมัติตั้งแต่วันที่") → ดูเฉพาะโฟลเดอร์วันที่ในช่วงนั้นใน Drive (service account อ่านอย่างเดียว) → ภาพใหม่เข้าตาราง `slips`
4. ต่อภาพ: อ่าน QR → `needs_details` (รอข้อมูล) / `qr_unreadable` / `duplicate` (ซ้ำ)
5. ภาพที่ไม่ซ้ำ: อ่าน OCR ด้วย Tesseract (~1–2 วินาที/ใบ โมเดลไทย/อังกฤษอยู่ในตัว API) → แยกยอด วันเวลา ชื่อ เลขบัญชีที่ปิดบางส่วน → เก็บเป็นร่างใน `slips.ocr_details`
   - อ่านชื่อเดือนไม่ออกแต่เลขวันตรงกับวันอัปโหลด → เติมเดือน/ปีจากวันอัปโหลด และติดป้ายให้ตรวจ
   - OCR ไม่สร้างรายการเงินเอง
6. ทำงานราว 3 นาทีต่อรอบ ที่เหลือรอบถัดไปทำต่อ ไม่มีของใหม่ก็จบในไม่กี่วินาที
7. Cron ส่งช้าไม่เกิน 4 นาที (ถึง 00:04) ยังสแกน หลังจากนั้นไม่สแกนจนคืนถัดไป

### 08:00: ส่ง Flex
- ทุกวัน: สรุปเมื่อวาน · วันจันทร์: + สัปดาห์ก่อน · วันที่ 1: + เดือนก่อน · ย้อนหลังได้ไม่เกิน 7 วัน
- เนื้อหา: ใช้ไป (เฉพาะรายการที่บันทึกแล้ว รวมโอนระหว่างบัญชีตัวเอง), แยกบัญชี · กล่องสถานะแสดงเฉพาะบรรทัดที่มีจริง: รอข้อมูล N สลิป, ร่าง OCR ยังไม่ตรวจ ฿X (ไม่บวกเข้ายอด) · ไม่มีเลยก็ไม่แสดงกล่อง · ปุ่ม "ดูสลิปรอข้อมูล" แสดงเฉพาะเมื่อมีสลิปรอ
- สลิปรอข้อมูลนับช่วงอัปโหลด 08:00 เมื่อวาน → 08:00 วันนี้
- ส่งผ่าน LINE Messaging API พร้อม retry key ไม่ส่งซ้ำ

### 08:05: ลองส่งซ้ำ
ส่ง 08:00 ไม่สำเร็จ → ลองที่ 08:05 → ยังไม่ได้ ลองรอบกลางคืน รวม 5 ครั้ง · ส่งครั้งแรกเกิน 23 ชั่วโมงแล้วหยุด กันข้อความซ้ำ

### ระหว่างวัน: ในแอป (กดเมื่อไหร่ก็ได้)
- **หน้าสลิป → ดึงสลิปตอนนี้**: เลือกช่วงวันที่ (ค่าเริ่มต้นวันนี้) และธนาคาร → ดึงจาก Drive + QR + OCR ทันที และอ่าน OCR ใบเก่าที่ยังไม่มีร่างให้ด้วย
- **หน้าสลิป → เลือกรูปสลิป**: อัปโหลดรูปเอง → QR + OCR → เปิดฟอร์มบันทึก ไม่เก็บรูป เก็บเลขอ้างอิงไว้กันซ้ำ ถ้าสลิปเดียวกันขึ้น Drive ภายหลัง รอบกลางคืนจะตั้งเป็น "ซ้ำ" ไม่นับยอดสองครั้ง
- ปุ่มดึงทำงานรอบละ 60 วินาที แอปเรียกต่อเองจนเสร็จ (สูงสุด 10 รอบ) ถ้า Cron กำลังทำงานจะแจ้งและไม่ทำซ้อน · ปุ่มนี้ทำแค่ดึงสลิป/QR/OCR **ไม่ส่ง Flex** (Flex ส่งเฉพาะรอบ 08:00 และปุ่มทดสอบ) · ระหว่างดึงมีแถบความคืบหน้า (ถาม `GET /api/sync/status` ทุก 2.5 วินาที: งานที่เสร็จ/ที่เหลือ สลิปที่พบ และเวลาที่ใช้) เสร็จแล้วขึ้นติ๊กถูก
- ฟอร์มบันทึก: ยอด วันเวลา ผู้รับ เติมจากร่าง · "โอนเข้าบัญชีของฉันไหม" เลือกบัญชีปลายทาง = โอน (เลือกให้อัตโนมัติถ้าเลขบัญชีผู้รับตรง) ไม่เลือก = ใช้ไป · คุณกดยืนยันเองทุกครั้ง
- ตั้งค่า: แก้/ลบบัญชี หมวด กฎ · "ดึงอัตโนมัติตั้งแต่วันที่" · **ทดสอบส่ง Flex ตอนนี้** (ยอดวันนี้ถึงตอนนี้ ไม่บันทึกเป็นรายงาน รอบ 08:00 ทำงานตามปกติ) · **รีเซ็ตเป็น 0** (ลบรายการและสลิป ตั้งวันเริ่มดึงเป็นวันนี้)
- แอปบันทึกเฉพาะยอดใช้ไปและโอนระหว่างบัญชี ไม่มีรายรับ

## รหัสลับอยู่ที่ไหน

| ที่เก็บ | ชื่อ |
|---|---|
| Supabase Vault | `expense_api_url`, `expense_cron_secret` |
| Vercel | `CRON_SECRET` (= `expense_cron_secret`), `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `GOOGLE_SERVICE_ACCOUNT_EMAIL`, `GOOGLE_PRIVATE_KEY`, `DRIVE_OWNER_ID`, `LINE_CHANNEL_ACCESS_TOKEN`, `LINE_CHANNEL_SECRET`, `APP_ORIGIN`, `OCR_ENABLED=true`, `OCR_ENGINE=tesseract` |
| GitHub Secrets | ไม่ต้องใช้ — ใส่เฉพาะเมื่อจะใช้แผนสำรอง Paddle |

## ถ้ามีอะไรพัง

| ปัญหา | ระบบทำอะไร |
|---|---|
| มือถือไม่อัปโหลด 23:30 | กด "ดึงสลิปตอนนี้" (เลือกวันได้) หรืออัปโหลดรูปเอง |
| สลิปเยอะสแกนไม่ทัน | รอบ 5 นาทีถัดไปทำต่อ ถึง 00:00 · ที่เหลือกด "ดึงสลิปตอนนี้" |
| OCR อ่านพลาด | ใบนั้นไม่มีร่าง กด "ดึงสลิปตอนนี้" ให้ลองใหม่ หรือกรอกเอง |
| OCR ไม่แม่นพอในระยะยาว | ใช้แผนสำรอง Paddle บน GitHub Actions |
| LINE ล่มตอน 08:00 | ลองใหม่ 08:05 และรอบกลางคืน |
| Cron/Vercel ล่มทั้งวัน | รอบ 08:00 ถัดไปส่งย้อนหลังไม่เกิน 7 วัน |

## เวลาใน cron เป็น UTC
ไทย = UTC+7 เช่น `35-55/5 16 * * *` = นาที 35–55 ทีละ 5 ของชั่วโมง 16 UTC = 23:35–23:55 ไทย · `tests/schedule.test.ts` ตรวจว่า `schedule.sql` ตรงกับตัวเช็กเวลาในโค้ด
