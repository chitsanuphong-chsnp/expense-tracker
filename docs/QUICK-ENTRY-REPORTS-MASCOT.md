# ปฏิทิน รายงาน และตัวละคร

## บันทึกรายการ

- แตะวันที่เพื่อเลือกจากปฏิทินภาษาไทย พร้อมปุ่มเลือกวันนี้ เลื่อนเดือน และวันที่ของเดือนข้างเคียง
- เวลารายการใหม่เริ่มจากเวลาไทยปัจจุบัน ส่วนการแก้ไขเก็บวันเวลาเดิม
- หลังบันทึกรายการใหม่สำเร็จ จำบัญชีสำหรับครั้งถัดไปในเครื่อง แยก key ของโหมดตัวอย่างและแต่ละเจ้าของข้อมูล
- การแก้รายการใช้บัญชีเดิม การเติมสลิปใช้บัญชีของแหล่งสลิปก่อนบัญชีล่าสุด และไม่เดาธนาคารจาก QR
- ภาพสลิปและช่องยอดอยู่หน้าเดียวกัน มือถือเรียงบน–ล่าง เดสก์ท็อปแยกสองคอลัมน์ ภาพที่โหลดสำเร็จแตะขยายได้
- โหลดภาพผ่าน API เดิมที่ตรวจเจ้าของข้อมูล ไม่มีลิงก์ภาพสาธารณะ โหมดตัวอย่างแจ้งชัดว่าไม่มีภาพจริง
- หน้า Record remount ตาม id/slip เพื่อไม่ใช้ยอดหรือ id เดิมเมื่อเปลี่ยนจากแก้ไขเป็นรายการใหม่

## รายงาน

- ปุ่มวันนี้/สัปดาห์นี้/เดือนนี้เลือกช่วงปัจจุบันได้ทันที สัปดาห์เริ่มวันจันทร์ ตาม Asia/Bangkok
- ปฏิทินเลือกช่วงย้อนหลัง และเปลี่ยนรายวัน/สัปดาห์/เดือนได้
- กราฟวงแหวนและเปอร์เซ็นต์มาจากยอดหน่วยสตางค์ใน summary เดิม ไม่รวมโอนระหว่างบัญชี
- แตะหมวดแสดงเปอร์เซ็นต์และยอดกลางกราฟ แตะซ้ำกลับยอดรวม รองรับหมวดที่ยังไม่จัด
- ไม่มีรายจ่ายแสดง empty state ไม่สร้างกราฟหรือยอดสมมติ

## ตัวละคร

- ใช้ภาพต้นฉบับสร้างด้วย built-in image_gen ภาพและ prompt อยู่ `examples/mascot-v1` และ `examples/mascot-v2`
- 5 ท่า: โบกมือ ยิ้มทักทาย อ่านสมุด ครุ่นคิด ดีใจ พร้อมลอย/เอียงตัวเบา ๆ และเด้งเล็กน้อยในท่าดีใจ
- ใช้ภาพครบตัวแต่ละท่า เพื่อรักษาสัดส่วนไหล่ ศอก และมือ ไม่มีการซ้อนแขนแยกชิ้น ภาพโบกมือและยิ้มปรับกรอบใน layout ให้จุดกึ่งกลางและฐานตัวละครตรงกับท่าอื่น โดยไม่แก้ไฟล์ภาพ
- เว็บใช้ CSS transform/opacity ให้ browser compositor ขยับ มือถือใช้ React Native Animated `useNativeDriver: true`
- ไม่เพิ่ม animation library, video, GIF หรือ React state update ที่ 60 ครั้ง/วินาที เปลี่ยนท่าอัตโนมัติทุก 8.5 วินาที พร้อม blend 200 ms
- แตะน้องเปลี่ยนท่า หรือไป ตั้งค่า → ดูท่าตัวละคร เพื่อเลือกครบทุกท่า
- ลดการเคลื่อนไหวและแอปอยู่เบื้องหลังหยุด loop และหยุดสลับท่าอัตโนมัติ ยังคงเลือกท่าแบบภาพนิ่งได้
- เป้าหมายใกล้ 60 fps ตามอัตรารีเฟรชและภาระเครื่อง ไม่มีการรับประกันทุกอุปกรณ์
- เครื่องมือตรวจเฉพาะ localhost: `/mascot-preview?perf=1` เก็บ sample `requestAnimationFrame` หลัง warm-up 30 เฟรม แล้ววัด 120 intervals ผลอยู่ใน DOM `mascot-frame-sample` ที่ซ่อนอยู่ ไม่ส่งออกไปภายนอก ไม่แสดงรายละเอียดทดสอบในหน้าจอปกติ

## ปรับสัดส่วนตัวละคร 6 ตุลาคม 2569

- ปรับท่าโบกมือ/ยิ้มให้หัว ลำตัว และแขนใกล้เคียงสัดส่วนของท่าอ่าน/คิด/ดีใจ จัดแขนไว้หลังไหล่เพื่อซ่อนปลายชิ้นส่วน
- ภาพแต่ละชิ้นรักษา aspect ratio จริง ใช้ contain แทน stretch
- เลิก overlay ภาพหัวกะพริบเดิม เพราะรูปทรงหัวไม่ตรงกับภาพตาเปิด (320×306 เทียบกับ 320×281) เก็บไฟล์ต้นฉบับเดิมไว้
- ไม่ใช้ scale ในการหายใจ ระยะลอย/เด้งแปรตามขนาดตัวละครแทนระยะพิกเซลคงที่ จึงไม่เด้งแรงบนการ์ดเล็ก
- หน้าหลักมือถือใช้กรอบกว้าง 76 px แถบตัวละครบนเดสก์ท็อป/รายงาน 68 px ทุกท่าใช้กรอบ 280:342 เดียวกัน
- Modal ยังคงใช้ภาพนิ่ง 42/56 px ไม่มีกรอบหรือ animation, ยกเลิกซ้าย/ยืนยันลบขวา; LINE Flex และ Noti ใช้ภาพนิ่งเดิมที่มีสัดส่วนครบแล้ว
- TypeScript app และ Expo Web/PWA export ผ่าน ตรวจ browser ที่ 390×844 และ 1440×1000: ห้าท่า หน้าหลัก รายงาน ปฏิทิน ยืนยันลบโดยกดยกเลิก Flex สามช่วง และ Noti จำลอง ไม่มี console error
- รอบนี้ไม่เพิ่ม dependency หรือสร้างภาพใหม่ ใช้ PNG ที่ bundle 6 ไฟล์รวม 234,625 bytes; ยังไม่ได้วัด FPS หรือรันทดสอบเครื่อง iPhone/Android จริง

## ตรวจแล้ว

### แก้แขนซ้อน — 6 ตุลาคม 2569

- การจัดแขนแยกชิ้นในรอบก่อนยังผิดธรรมชาติ เพราะ body-v2 มีแขนซ้ายอยู่แล้ว จึงเปลี่ยนท่าโบกมือ/ยิ้มเป็นภาพครบตัว wave-v1/idle-v1 เก็บภาพต้นฉบับทุกไฟล์ไว้
- ภาพครบตัวห้าท่าคง animation แบบ transform/opacity, blend 200 ms, auto pose ทุก 8.5 วินาที และหยุดเมื่อ reduced motion/เบื้องหลัง ท่าโบกมือขยับทั้งตัวเบา ๆ ไม่หมุนแขนแยกอีก
- TypeScript app และ Web/PWA export ผ่าน ตรวจภาพทั้งห้าท่าบนเดสก์ท็อป 1280×720 และหน้าหลักมือถือ 390×844 ไม่มีแขนซ้อน
- ตัวตรวจเฟรม localhost ใช้ selector ของท่าปัจจุบันแทนแขนที่เลิกใช้แล้ว sample ของท่าโบกมือ: rAF 142.8 Hz, median 6.9 ms, p95 7.1 ms, transform เปลี่ยน 121 ค่า เป็นผลเฉพาะเบราว์เซอร์เครื่องนี้ ไม่ยืนยัน FPS บนอุปกรณ์จริง
- ไม่สร้างภาพใหม่ ไม่เพิ่ม library และไม่เปลี่ยน mascot ภาพนิ่งใน modal/LINE

- ปฏิทิน leap year, เดือน 6 สัปดาห์, ย้อน/ข้ามปี และวันผิดที่ rollover: 4 tests ผ่าน
- ชุดทดสอบทั้งหมด 26 tests ผ่าน และ TypeScript ผ่าน
- รายงานเดือนตัวอย่าง ฿1,770, สัปดาห์ ฿330, วันปัจจุบัน ฿0; ย้อนปฏิทินวันที่ 30 ก.ย. ได้ ฿450
- แตะอาหารในกราฟสัปดาห์ แสดง ฿85 และ 25.8%
- เพิ่มเงินสด ฿15.75 วันที่วันนี้ ยอดวันนี้/เงินสด ฿15.75 เดือน ฿1,785.75 และบัญชีเงินสดยังถูกเลือกหลัง reload จากนั้นลบเฉพาะรายการทดสอบ คืนข้อมูลเดิม 18 รายการ
- หน้าแก้สลิปที่เชื่อมแสดงภาพและยอดในหน้าเดียว บัญชี K-PLUS เดิมไม่ถูกเปลี่ยนเป็นบัญชีเงินสดล่าสุด
- เว็บ export ผ่าน และ iOS/Android Hermes export ผ่าน ไม่เท่ากับทดสอบ Expo Go บนเครื่องจริง
- ตรวจ 320×740, 390×844 และเดสก์ท็อป 1440×1000 ไม่มี document overflow ที่ 320px และกราฟเดสก์ท็อปแสดง legend ข้างวงแหวน
- เลือกท่าโบกมือ อ่านสมุด ครุ่นคิด และดีใจจาก UI ได้ ภาพแขนแยกชิ้นมี CSS rotation ต่อเนื่อง
- เปิดลดการเคลื่อนไหวแล้ว `mascot-arm` และ `mascot-motion` มี animation/transform เป็น `none` จากนั้นคืน preference เดิมเป็นปิด
- ไฟล์ PNG ที่ bundle ตัวละคร v2 ใช้ 7 ไฟล์ รวม 285,897 bytes ไม่มี video/GIF/animation dependency ใหม่
- ตัววัด `requestAnimationFrame` ใน in-app browser ยังไม่คืนผลสมบูรณ์ จึงไม่รายงานเลข FPS ที่วัดแล้ว เป้าหมาย 60 fps ต้องยืนยันบน Chrome และอุปกรณ์จริง

ยังไม่มี Drive/Supabase จริง จึงตรวจสถานะไม่มีภาพใน demo ได้ แต่ยังไม่ได้ตรวจการดาวน์โหลด/ขยายภาพสลิปจริงจาก Cloud หรือ fps บนอุปกรณ์ iPhone/Android
