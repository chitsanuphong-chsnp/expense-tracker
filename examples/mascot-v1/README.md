# Anime mascot v1

Generated with the built-in image_gen tool. Transparent original sprite sheet is preserved here; three optimized PNG poses are bundled under apps/app/assets/mascot. The fourth pose was excluded because its waving arm changes sides. Camera/baseline normalization and PNG compression only; no new image details were drawn.

Motion: gentle 3 px float, occasional blink and hand wave. Stops for reduced motion and when the app is inactive.
